# Редакция газеты губернаторского лицея

Публичная газета: https://azotishka.github.io/Neuro-assistent/
Редактор: https://azotishka.github.io/Neuro-assistent/admin/

## Доступ и безопасность

Сайт работает только на GitHub Pages (без серверной части). Общий шестизначный пароль НЕ может безопасно предоставлять право записи: любой проверяемый в браузере пароль можно прочитать или обойти, а записывать изменения в репозиторий всё равно должен уполномоченный GitHub-пользователь.

Редактор полностью статический, не запрашивает пароли или персональные токены доступа и не добавляет сторонние скрипты. Любой человек, знающий ссылку, может подготовить публичный текст в форме; это не даёт ему возможности опубликовать его. Для записи материалов владелец репозитория выдаёт сотруднику право на запись в GitHub. Доступ проверяет GitHub при сохранении изменений. Не передавайте свои пароли и токены другим сотрудникам.

## Как опубликовать новый выпуск с телефона

1. Откройте страницу /admin/ и заполните дату, номер, заголовок, краткое описание и текст.
2. Нажмите «Скопировать текст для GitHub» (или скачайте .md).
3. Нажмите «Создать файл в GitHub». Войдите в аккаунт GitHub с правами записи, если система попросит.
4. Создайте Markdown-файл с именем, показанным на странице редактора. Вставьте в него скопированный текст.
5. Выберите Commit changes. Если у сотрудника нет прямой записи в gh-pages, он может предложить изменение через pull request, а владелец репозитория должен его принять.
6. После успешного запуска workflow «Publish school newspaper» новый номер появится в архиве.

## Как изменить существующий выпуск

1. В /admin/ выберите выпуск из списка.
2. Измените текст и нажмите «Скопировать текст для GitHub».
3. Нажмите «Редактировать файл в GitHub» и замените содержимое существующего .md-файла.
4. Сохраните изменение через Commit changes и дождитесь успешного завершения GitHub Actions.

Файлы номеров: `content/issues/*.md`.

## Как работает каталог

При каждом push в gh-pages, затрагивающем папку школьной газеты, GitHub Actions запускает `build_catalogue.py`, создаёт свежий `content/issues.json` из всех .md-файлов и публикует корень ветки `gh-pages` на GitHub Pages. Файл issues.json в исходной ветке может содержать старую копию и не является источником правды для новых материалов: для публикации актуальный каталог создаётся во время сборки.

Все материалы, попавшие в репозиторий и опубликованный каталог, публичны. Не добавляйте сведения о школьниках, фотографии и интервью без соответствующих разрешений.

## Если выпуск не появился

Откройте репозиторий → Actions → Publish school newspaper. Если сборка завершилась ошибкой, проверьте формат метаданных в новом файле. Каждый .md-файл должен содержать поля title, issue_number, date (YYYY-MM-DD), theme, summary между строками --- и непустое тело статьи. Двойные кавычки и обратные слэши в строках следует экранировать, как это автоматически делает редактор.

В случае необходимости workflow можно запустить вручную в Actions. Паролей и токенов в исходном коде газеты нет.

## Важное о ветках

Опубликованный сайт находится в корне ветки `gh-pages`. Редактор открывает файлы этой ветки. Изменения только в `main/school-newspaper-site` не публикуются автоматически; для обновления сайта редактируйте файлы ветки `gh-pages` или синхронизируйте её содержимое. Workflow запускается при изменениях в `gh-pages`, формирует актуальный архив и развёртывает сайт.
