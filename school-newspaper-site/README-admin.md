# Администрирование школьной газеты

Сайт работает на GitHub Pages как статический сайт. Это значит, что он не хранит пароли и не имеет собственного сервера.

## Как добавить выпуск

1. Откройте страницу `/admin/` опубликованного сайта.
2. Нажмите вход через токен GitHub.
3. Создайте fine-grained personal access token для репозитория `Azotishka/Neuro-assistent` с доступом `Contents: Read and write`.
4. Вставьте токен в окно входа.
5. Создайте новый выпуск, заполните номер, дату, тему, краткое описание и текст.
6. Сохраните выпуск. После публикации GitHub Pages обновит сайт автоматически.

## Кто может редактировать

Редактировать могут только люди, которым владелец репозитория выдал подходящий доступ GitHub или токен. На статическом GitHub Pages нельзя безопасно разместить общий пароль или секрет OAuth прямо в файлах сайта.

## Где лежат выпуски

Все номера газеты хранятся как Markdown-файлы в папке:

`school-newspaper-site/content/issues`

Если админка временно недоступна, выпуск можно добавить вручную через GitHub, создав новый `.md` файл с теми же полями в начале файла.
