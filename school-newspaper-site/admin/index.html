Редактор выпусков

Создавайте и правьте выпуски прямо на телефоне. Текст готовится здесь, а публикация подтверждается в вашем аккаунте GitHub.

Как устроен доступ

Эта страница общедоступна: она не раскрывает черновики и не даёт прав на изменение сайта. Публиковать могут только сотрудники, которым владелец репозитория выдал доступ на запись в GitHub. Шестизначный общий пароль нельзя безопасно проверить на одном лишь GitHub Pages, поэтому здесь нет ложного «входа по паролю».

Ни пароль, ни GitHub-токен сайт не запрашивает, не хранит и не отправляет. При публикации GitHub попросит войти обычным способом.

03 / Выход в свет

Сохранение и публикация

Сначала подготовьте выпуск, затем скопируйте или скачайте файл. В GitHub добавьте его как Markdown-файл и подтвердите изменение. После сохранения сайт пересоберёт архив автоматически.

Вход в GitHub потребуется только при сохранении изменений в репозитории.

Как опубликовать выпуск на телефоне
  1. Заполните поля и нажмите «Скопировать текст для GitHub».
  2. Откройте GitHub по кнопке выше и войдите в аккаунт, у которого есть право редактировать репозиторий.
  3. Для нового выпуска создайте файл с указанным именем и вставьте скопированный текст. Для существующего откройте редактирование его файла и замените содержимое.
  4. Сохраните изменение (Commit changes). GitHub Pages автоматически обновит каталог после завершения публикации.
