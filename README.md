# NeuroAssistant 0.9

Android-помощник с единым интерфейсом Qwen Local 3.9.4. Один экран чата хранит сообщения от локальных моделей WebLLM, совместимого с OpenAI API и команд Android. При первом запуске обновлённого приложения старая история нативного чата импортируется в список разговоров. Кнопка 🎙 запускает системную диктовку и вставляет текст в поле ввода.

## Запуск на телефоне

1. Установи APK из последнего успешного [GitHub Actions](https://github.com/Azotishka/Neuro-assistent/actions/workflows/build-apk.yml), открой приложение.
2. Выбери «На устройстве» и загрузи подходящую модель в разделе «Модели». Для запуска нужен WebGPU в Android System WebView, достаточная память и интернет при первой загрузке весов; веса не включены в APK.
3. Если WebGPU недоступен, открой «Настроить API и кнопку телефона», укажи HTTPS-адрес совместимого провайдера, модель, API-ключ, сохрани и выбери «Через API». Передача запроса и последних сообщений начнётся только после явного выбора режима API. Ключ шифруется Android Keystore и не передаётся веб-интерфейсу.
4. Чтобы открыть приложение системным жестом или доступной кнопкой ассистента, нажми «Выбрать ассистентом» и выбери NeuroAssistant в системном окне Android. Конкретный жест зависит от телефона и прошивки; кнопку питания приложение не перехватывает.
5. «Ожидание» включает постоянное уведомление с быстрым запуском диктовки. Его можно выключить в настройке приложения или уведомлении. Постоянное прослушивание и фоновая генерация не реализованы.

Системные команды: «открой настройки», «открой вайфай», «открой блютуз», «открой камеру», «открой YouTube», «открой карты», «открой телефон», «открой браузер». Команды открывают системное приложение и сохраняют ответ в текущем чате при любом выбранном режиме.

## Сборка

Workflow `.github/workflows/build-apk.yml` выполняет unit tests, Android Lint и `assembleDebug`, затем загружает артефакт APK. Debug APK подписывается временным ключом сборочного окружения GitHub Actions. При несовпадении подписи с ранее установленной версией Android потребует удалить старое приложение; перед этим экспортируй важные чаты из меню данных. Для обновлений без удаления нужна постоянная приватная подпись релиза.

Данные чатов живут в IndexedDB Android WebView. Доступ к нативным командам ограничен основным фреймом локального `https://appassets.androidplatform.net`. Для API допускается HTTPS; HTTP-трафик приложения отключён. Работу локальной модели на конкретном телефоне необходимо проверить отдельно: наличие APK не гарантирует поддержку WebGPU.
