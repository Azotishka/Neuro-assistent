Как устроен доступ

Эта страница общедоступна: она не раскрывает черновики и не даёт прав на изменение сайта. Публиковать могут только сотрудники, которым владелец репозитория выдал доступ на запись в GitHub. Шестизначный общий пароль нельзя безопасно проверить на одном лишь GitHub Pages, поэтому здесь нет ложного «входа по паролю».

Ни пароль, ни GitHub-токен сайт не запрашивает, не хранит и не отправляет. При публикации GitHub попросит войти обычным способом.

Как опубликовать выпуск на телефоне
  1. При наличии вложения выберите файл, нажмите «Загрузить выбранный файл в GitHub», выберите тот же файл на странице GitHub и подтвердите сохранение.
  2. Заполните поля и нажмите «Скопировать текст для GitHub».
  3. Откройте GitHub по кнопке выше и войдите в аккаунт, у которого есть право редактировать репозиторий.
  4. Для нового выпуска создайте файл с указанным именем и вставьте скопированный текст. Для существующего откройте редактирование его файла и замените содержимое.
  5. Сохраните изменение (Commit changes). GitHub Pages автоматически обновит каталог после завершения публикации.
