## Новые выпуски с PDF / Word / изображениями

1. Откройте `/admin/`, заполните данные и текст.
2. Выберите файл на устройстве (PDF, DOC/DOCX, ODT, RTF, TXT, PPT/PPTX, XLS/XLSX, CSV, JPG/PNG/WEBP, ZIP; до 25 МБ).
3. Нажмите «Загрузить выбранный файл в GitHub» и **выберите тот же файл ещё раз** на странице GitHub. Подтвердите Commit changes в ветку `gh-pages` в папку `content/files/`. Имя файла не меняйте.
4. Вернитесь в редактор, скопируйте Markdown и сохраните его через «Создать файл в GitHub» в `content/issues/` той же ветки.
5. Дождитесь успешного завершения Actions → Publish school newspaper. PDF откроется внутри страницы и по ссылке; Word и прочие форматы открываются или скачиваются средствами браузера.

GitHub Pages — статический хостинг: локальный выбор файла в редакторе **не означает загрузку на сервер**. Права записи проверяет GitHub, а не клиентский пароль. Никаких паролей или токенов в исходном коде нет. Любой файл, загруженный в публичный репозиторий, будет общедоступен; не публикуйте персональные сведения без разрешений.
